# Stagnation: Delay — 关卡完整设计文档（纯设计版）

> 核心体验：一条线在「滞后」的世界里追赶自己的回声  
> 形式：3D 节奏线控跑酷 · 单关卡四段落 · 段落解锁制  
> 主题：**延迟 Delay** —— 行动滞后、记忆滞后、情感滞后

---

## 一、整体关卡流程概览

| 阶段 | 场景意象 | 时长 | 节奏 | 核心体验 | 情感弧光 | 解锁条件 |
|------|----------|------|------|----------|----------|----------|
| **P1 初滞** | 暖黄峡谷，世界在呼吸 | ~90s | 80 BPM 缓慢钢琴 | 学会预判「卡顿」，感受失控后的规律 | 迷茫 → 好奇 → 掌控感萌芽 | 初始开放 |
| **P2 回声** | 灰蓝山谷，残影并行 | ~120s | 100 BPM 弦乐入 | 跟随 3 秒前的自己，发现过去在保护现在 | 恐惧 → 信任 → 温情 | 通关 P1 |
| **P3 终章·假终点** | 破晓拱门，光芒刺眼 | ~90s | 120 BPM 全乐团 | 全程慢动作，最后冲刺穿过拱门——却被判定「未到达」 | 期待 → 困惑 → 渴望真相 | 通关 P2 |
| **P4 回声之境（隐藏）** | 镜面回廊，万象倒影 | ~50s | 80 BPM Remix | 收集回声碎片维持「同步率」，过高即死，过低停滞 | 紧张 → 释然 → 完整 | 通关 P3 假终点 |

> **两种模式**  
> - **分段模式**：任选已解锁段落练习  
> - **完整模式**：P1→P2→P3 无缝连跑 → 解锁 P4 隐藏段

## 附：当前落地状态与视觉审查（2026-08-05）

> 上面的内容是设计目标。本节以当前关卡场景的场景树和运行态截图为准，区分已经存在的内容与仍然缺失的体验。未列为“已验证”的内容，不应在宣传或验收中当作完成。

| 段落 | 当前落地 | 主题偏差 / 缺口 |
|------|----------|----------------|
| **P1 初滞** | `part1`、暖黄路径、深色峡谷物件和引导线已存在 | “滞后”主要仍由静态蓝线表达；卡顿、色差、音频失真没有在当前回声之境运行态闭环证明 |
| **P2 回声** | `part2` 已有山体、水面和雾效触发器 | 3 秒前的残影、残影拖尾和“安全路径”没有在场景树中形成可验收的独立视觉对象 |
| **P3 假终点** | `part3` 已有拱门、四组镜面破碎触发器和 Pyramid 结束结构 | 渐白、静音、假终点文字和完整模式解锁尚未作为一条运行态流程验证 |
| **P4 回声之境** | 当前场景没有 `part4` | 镜面回廊、同步率、回声碎片、碎片门、残影汇聚和最终文案均未落地 |
| **Autoplay** | 当前工作区已接入默认入口 | 后段行为由单独调试处理；本节不把入口接入视为后段完成 |

### 视觉审查结论

当前运行截图的主视觉是冷灰机器人、暖黄色大面积路径、深灰墙体和一条蓝色引导线。低多边形方向成立，但“滞后”还没有成为画面中的动作语言：玩家能看到路，却看不出“现在”和“回声”之间的时间差。皮肤选择器与设置栏同时占据左下和底部区域，也抢过了关卡本身的第一视觉焦点。

优先级应按以下顺序推进：

1. **先收回首屏焦点**：进入游玩后只保留必要的轻量状态提示，皮肤和设置面板改为主动打开；不要让调试/配置层覆盖路径和机器人。
2. **让 P1 可见地“慢半拍”**：在卡顿点增加短暂的路径残留、机器人位置回弹或颜色分离，并让反馈只在事件发生时出现，避免常驻滤镜。
3. **让 P2 出现真正的回声**：加入可辨识的半透明玩家残影与延迟拖尾，残影必须和当前路线存在可比较的前后关系。
4. **让 P3 的拱门承担假终点**：拱门前后需要明确的亮度跃迁、冻结和留白，文案出现前先给玩家一个“已经结束”的错觉。
5. **最后独立制作 P4**：不要继续用 P3 的镜面破碎触发器代替回声之境；P4 需要自己的镜面地面、残影层和终点汇聚构图。

## 二、路线设计 — 节奏即几何

### 设计原则
- **拍点即转折**：每个转向、跳跃、卡顿点落在音乐重音上
- **0.3 秒预判窗**：玩家需在拍点前瞬间按下，线条才会在拍点转向
- **几何语言递进**：直线大弯 → S弯分岔 → 宽阔冲刺 → 镜面迷宫
- **视觉自引导**：路径节点随乐闪烁、残影指路、雾光勾勒前进方向

### 四段落路线拓扑

**P1 呼吸的峡谷**  
起点自动前行 → 直道 8 拍 → 左弯 45° → 直道 4 拍 → 右弯 60° → 直道 8 拍 → 首次卡顿  
随后每 8 拍一次「世界呼吸」：画面冻结半拍、色彩分离、音频失真，玩家学会在卡顿前调整方向

**P2 残影的抉择**  
雾化过渡进入山谷 → 分岔口 A（残影走左） → 汇合 → 分岔口 B（残影走右） → 汇合 → 收窄走廊 → 远方拱门轮廓  
残影走过的路是安全的；偏离残影，预警线变红、前方陷阱显现

**P3 破晓前的滑步**  
山谷尽头 → 宽阔直道（全程半速） → 阳光穿透云层 → 发光拱门渐近  
最后 20% 路程速度骤增、视野拉宽、拱门光芒爆发 → 穿过拱门瞬间做一次「机车式滑步过弯」 → 画面渐白、音乐戛然而止

**P4 同步率博弈**  
拱门后地面化为破碎镜面，倒映三段往昔 → 直道（碎片稀疏） → S弯（碎片内外侧各半） → 连续卡顿 S弯（高密度） → 碎片门（三枚必经碎片物理阻挡） → 最后一面镜子破碎 → 残影引路 → 中心汇聚点
收集碎片↑同步率，时间流逝↓同步率，100% 即死；健康区间 60-90%，「保持 3 秒滞后的并肩」

## 三、场景氛围与光雾设计

### P1 初滞——暖黄峡谷·呼吸的雾
- **天空**：程序化暖黄天空，地平线 #FFD700，头顶 #FFA500，地面暗蓝 #1A1A2E
- **雾**：线性雾，近裁 15m 远裁 120m，深蓝 #003366（α 35%），峡谷底部高度雾堆积
- **光**：侧后方 45° 暖黄阳光 #FFE87C，能量 2.8，柔和阴影，微弱体积光轴
- **色调**：对比度微增、饱和度 1.1，暖黄与深蓝补色分明
- **关键瞬间**：卡顿时 RGB 色差拉大、体积光轴放大、Bloom 触发

### P2 回声——灰蓝山谷·压抑的纵深
- **天空**：能量降至 0.6，地平线灰蓝 #374151，天顶深灰蓝 #1E293B
- **雾**：指数平方雾，密度 0.018，颜色 #2D3748（α 55%），山谷底极浓、脊线稀薄
- **光**：低仰角冷白月光 #A0AEC0，能量 1.2，大面积柔影，明显体积光轴穿透雾气
- **色调**：对比度 1.1、饱和度 0.85，冷调 LUT（蓝通道提、红通道压）
- **残影视觉**：半透明淡蓝拖尾粒子，随音乐脉动缩放

### P3 终章——破晓拱门·光的洪流
- **雾**：线性雾，近裁 40m 远裁 300m，颜色从 #1A1A2E 渐变至 #FFD700，取消高度雾
- **天空**：能量 1.5→3.0，地平线从 #2D1B00 到 #FFA500，天顶从深蓝到近白
- **光**：仰角 -15° 近正午，暖黄→纯白 #FFF8E7，能量 3.5→6.0，锐利阳光盘，强体积光束「上帝之光」
- **Bloom**：强度 0.6→1.8，阈值降至 0.8，拱门光芒溢出全屏
- **色调**：对比度 1.0→1.15，饱和度 1.0→1.3，色彩随光逐渐饱和
- **动态过渡**：110-125 秒区间所有参数平滑插值，破晓过程全程可控

### P4 回声之境——镜面回廊·万象倒影
- **无全局雾**，极远景仅保留极薄线性雾作深度
- **天空**：360° HDR 全景，烘焙三段关键地标剪影（峡谷柱子、山谷拱门、破晓光束）
- **光**：正上方纯白光，无阴影方向性，环境光能量 1.5 全向补光
- **镜面地面**：屏幕空间反射，菲涅尔 0.3，微模糊 0.02，破碎感
- **同步率联动视觉**：
  - 0-60%：青蓝边缘呼吸光晕，冷静
  - 60-90%：金色加速脉动，背景音乐变闷、心跳声叠加
  - 90-100%：红金色差抖动、声音变尖锐、最后 3 秒强制慢动作
- **Tonemap**：Reinhard 曲线，柔和压缩高光，避免镜面过曝

## 四、玩家与场景的互动体验

### 核心手感
- **点击转向**：鼠标左键 / 空格 / 屏幕左右半区，线条像机车过弯先压重心再滑步转向
- **延迟响应**：输入后 0.3 秒线条才转向，需预判拍点；设置菜单可微调 ±0.1s
- **首次转向**：启动游戏、淡出开始页、音乐同步播放
- **卡顿判定**：每 8 拍强制减速半秒，画面冻结、色差、音频失真三重反馈
- **残影跟随**：P2 起自动生成半透明「3 秒前的自己」，带淡蓝拖尾，走过的路安全
- **P4 残影引路**：最后一面镜子破碎后，残影提前完成下一个转向并停下等待玩家；它只提供方向，不替玩家移动或输入
- **假终点演出**：穿过拱门 → 滑步转向 → 渐白 → 静音 → 文字「真正的终点，还在更远处」 → 解锁完整模式
- **同步率系统（P4）**：自然衰减、拾取回升、边缘光晕/心跳/低通滤波三重可视化，100% 即死「你追上了过去，却丢失了现在」

### 关键交互节点
| 交互 | 触发时刻 | 玩家感受 | 视听反馈 |
|------|----------|----------|----------|
| 首次转向 | 起点 10 秒 | 身体比意识慢一拍 | 音乐启动、开始页淡出 |
| 卡顿适应 | 30-60 秒 | 世界在呼吸，滞后可预测 | RGB分离、失真、节奏内化 |
| 残影相遇 | P2 45 秒 | 过去在保护现在 | 淡蓝拖尾、弦乐渐强 |
| 假终点 | P3 结尾 | 以为抵达实则半程 | 滑步、渐白、戛然而止 |
| 碎片门 | P4 终点前 | 必须拥抱回声才能通过 | 心跳拉满、物理阻挡 |
| 最后一面镜子 | P4 终点前 | 过去转化为方向 | 镜面静止、残影先行、停下等待 |
| 最终汇聚 | P4 结束 | 迟到的温柔终于抵达 | 所有残影向心汇聚、主题完整奏响 |

## 六、独特机制的感受层设计

### 滞后响应（核心手感）
- 默认 0.3 秒延迟，菜单可微调
- 系统音频延迟自动补偿，无感同步
- 卡顿持续 0.5 秒，前 0.5 秒边缘扭曲预兆

### 残影系统（P2-P4）
- 3 秒固定延迟，半透明淡蓝，拖尾粒子随乐脉动
- 最多三套残影同时存在（P1/P2/P3 各一），P4 同屏回放
- 编辑器可预览残影轨迹

### 同步率博弈（P4 核心）
- 初始 60%，自然衰减 1.5%/秒，拾取碎片 +8%
- 健康区 60-90%（青蓝→金光晕），濒死区 90-100%（红金色差、心跳、慢动作）
- 100% 即死：专用结算文案「你追上了过去，却丢失了现在」
- 终点强制锁定 99%，所有残影同步滑步汇聚消失

### 假终点演出（P3 高潮）
- 穿过拱门 → 机车式滑步转向 → 画面渐白 → 音乐戛然而止 → 文字淡入 → 解锁完整模式
- 情感设计：制造「错过」，真正的答案被「延迟」释放

## 七、关卡制作指引（给关卡设计师）

### 新建关卡流程
1. 工具栏「Template → 新建关卡」输入名称
2. 自动生成场景文件 + LevelData 资源，分配唯一 ID

### 路线铺设
- 用 Path3D 对齐拍点，PathFollow3D 绑定进度
- 每拍点放置 Marker3D 命名 Beat_001 等，供碎片生成参考

### 触发器布置（组件化）
1. 实例化 Trigger 容器 → 调整碰撞体覆盖区域
2. 添加子节点 Node3D → 挂载对应行为脚本（转向/变速/跳跃/相机/雾/动画等）
3. 容器属性：一次性触发、仅游玩时生效

### P4 碎片密度烘焙
- 选择路径 → 选预设密度曲线（对应 Remix 四段） → 一键生成 → 微调 → 烘焙固定

### 验收清单
- [ ] 延迟校准菜单生效，手感符合预期
- [ ] P1 卡顿画面冻结/色差/失真同步
- [ ] P2 残影 3 秒延迟、半透明、拖尾、安全路径正确
- [ ] P3 半速→冲刺、假终点演出完整
- [ ] P4 同步率 HUD/衰减回升/碎片门阻挡符合数值表
- [ ] 音乐无缝衔接（分段原版 / 完整模式 Hybrid）
- [ ] 物理碰撞无穿模、检查点复活正确
- [ ] 调试显示同步率/时间/段落/帧率正常

## 十、DLC 扩展：深渊回响（The Abyss Echo）

> 完整模式通关后解锁。不在新地图上展开，而是让回声之境对记忆做一次「倒带重播」：机器人被送回 P1 起点，在 P1→P2 的衔接处坠入深渊——那是被跳过的、未被记录的缝隙。深渊里只有前方一点微光，循光而上，最终与所有残影在终点汇聚。

### 流程拓扑

```
P1 起点（褪色重播）→ P1→P2 衔接处地面崩裂 → 坠入深渊（3~5 秒自由落体，只观察不操作）
→ 深渊黑暗段（仅光点指引）→ 光渐亮段（视野与节奏同步恢复）→ 逃出洞口（晨光涌入）
→ 直接切入回声之境汇聚点 → 与所有残影融合
```

### 场景与光雾

| 阶段 | 场景 |
|------|------|
| 重播段 | 复用 P1 暖黄峡谷，但饱和度下调、色调偏冷，像褪色的旧录像；节点光点比记忆中暗淡 |
| 深渊段 | 几乎全黑，无天空无地平线，仅前方一个光点；线性雾极浓，四周岩壁只剩轮廓 |
| 光变亮 | 光源强度随进度线性上升，雾从深黑→深蓝→暖灰→晨光，Bloom 渐强 |
| 洞口 | 仰角光柱，白光溢出，是 P3「破晓拱门」的纵向镜像 |

### 机制与手感

- **光点即节拍**：深渊段没有常规节奏点，唯一节拍提示来自前方光点——每拍脉动一次（延续 P1「节点随乐闪烁」，也是「跟随前方微光」的字面化）
- **视野绑定节奏**：光越亮，可视范围越大、转弯提示越清晰；难度在黑暗中压到最低、在洞口处回升
- **坠落即观察**：坠落瞬间 3~5 秒无操作、只有下落与风声，呼应 P1「世界在呼吸」的观察性段落
- **终点复用**：冲出洞口后直接切入回声之境汇聚点，复用 P4 残影向心汇聚的演出

### 主题对照

| 设计 | 对应「滞后」主题 |

| 倒带重播 | 记忆可以重放，滞后是循环的而非单向的 |
| 坠入衔接缝 | 直面「遗失的核心记录」，跌进被跳过的时间 |

### 技术要点（新增）

| 机制 | 实现方案 |
|------|----------|
| 倒带重播 | 完整模式结算后，复用 P1 场景实例加载，`LevelManager` 重置段落状态 |
