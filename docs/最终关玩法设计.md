# 最终关玩法设计：回声之境——同步率博弈

> **触发条件**：通关段落 3 假终点 → 解锁「完整模式」 → 3 段连跑后进入隐藏第四段  
> **核心主题**：「滞后的终点是同步，但过度同步即吞噬——健康的关系是保持 3 秒滞后的并肩」  
> **音乐策略**：**分段模式用原版，完整模式前三段接原版、隐藏段切 Remix**
>
> | 模式 | 段落 | 音乐来源 | 时长 | BPM |
> |------|------|----------|------|-----|
> | **分段模式** | 段落 1 初滞 | 原版 Part1 | ~90s | 80 |
> | | 段落 2 回声 | 原版 Part2 | ~90s | 100 |
> | | 段落 3 终章 | 原版 Part3 | ~70s | 120 |
> | **完整模式** | 段落 1+2+3 连跑 | **原版 Part1→2→3 无缝衔接** | ~4:10 | 80→100→120 |
> | | **隐藏第四段** | **Remix Section D + Outro** | **~50s** | **80** |
> | | 假终点 Bridge | 原版 Part3 结尾静音 | 2拍 | — |

## 一、核心数值：同步率

| 参数 | 数值 | 体验含义 |
|---|---|---|
| **数值范围** | 0% – 100% | 0 = 完全滞后（安全但无法推进），100 = 完全同步（瞬间死亡） |
| **初始值** | 60% | 进入隐藏段时的基础同步率 |
| **自然衰减** | -1.5%/秒 | 时间在拉大你与过去的距离——不主动连接，滞后只会变大 |
| **收集回升** | +8%/个 | 拾取「回声碎片」瞬间回升，伴随钢琴泛音，音高随同步率升高 |
| **死亡阈值** | ≥ 100% 瞬间判定 | 「你追上了过去，却丢失了现在。」专用结算文案 |
| **安全区** | 0% – 60% | 青蓝微光，无压力 |
| **警戒区** | 60% – 90% | 金色加速脉动，背景音乐变闷，心跳声叠加 |
| **濒死区** | 90% – 100% | 红金色差抖动，声音变尖锐，最后 3 秒强制慢动作 |

---

## 二、收集物：回声碎片

| 属性 | 设计 |
|---|---|
| **视觉** | 半透明低多面体几何体（四面体/八面体/二十面体随机），表面流动着三段落主题色（青绿→灰蓝→暖金） |
| **动画** | 随音乐节拍缩放脉动，悬浮高度 ±0.3m 正弦波动 |
| **拾取反馈** | 1. 碎片化为粒子流飞入玩家残影轨迹<br>2. 钢琴泛音，音高随同步率升高<br>3. 屏幕边缘光晕闪烁一次（青蓝→金）<br>4. 残影亮度瞬间提升，0.5 秒内衰减 |
| **生成逻辑** | 沿主路径两侧按音乐段落密度曲线程序化生成，**不手动摆放** |
| **回收机制** | 玩家通过后 2 秒未拾取 → 自动淡出销毁，**不扣除同步率**（只奖励不惩罚） |

## 三、隐藏段节奏曲线（总长 ~50 秒，对应 Remix Section D + Outro）

| 音乐时间 | 游戏时长 | 碎片间隔 | 同步率压力 | 关卡几何 | 叙事文字（淡入淡出） |
|---|---|---|---|---|---|
| **Remix 4:10–4:25** | 15s | 3.0s/个 | 低 | 直道，碎片在路中心线单侧交替 | 「回声在呼唤，别让它们靠太近」 |
| **Remix 4:25–4:40** | 15s | 2.0s/个 | 中 | 引入左右弯道，碎片分布内外侧各半，需规划收集线 | 残影开始在镜面两侧并跑，「它们走过的路，是你将走的路」 |
| **Remix 4:40–4:55** | 15s | 1.2s/个 | 高 | 连续 S 弯 + 卡顿判定点，碎片密集，**必须预判收集** | 「太靠近了——保持距离，才能并肩」 |
| **Remix 4:55–5:00** | 5s | 0.8s/个 + **必经碎片门** | 极高 | 终点前 3 个碎片形成「门」，**不拾取无法通过**（物理阻挡），同步率被迫冲至 95%+ | 无文字，仅音频：心跳拉满 → 终点汇聚瞬间 **全静** |

**完整模式音乐衔接点：**
- **0:00–4:10**：原版 Part1 → Part2 → Part3 无缝衔接（BPM 80→100→120）
- **4:10**：原版淡出 → Remix Section D 淡入（同步率初始化 60%）
- **5:00**：Bridge 突发静音 2 拍 → 「真正的终点还在更远处」
- **5:02**：Outro 大提琴独奏 → 终点汇聚 → 最终文案**

**终点汇聚演出（最后 2 秒，对应 Remix Outro 大提琴长延音）：**

1. 同步率强制锁定 99%（不再衰减/增长）
2. 所有残影（段落 1/2/3 残影 + 当前残影）同时触发「滞后转向」动画，向中心汇聚
3. 缩放淡出同步消失
4. 屏幕中央逐字显现最终文案：**「迟到的温柔，终于抵达。」**（配主题旋律完整奏响，钢琴琶音落于 G 大调和弦，自然混响衰减 5 秒）

### 最后一面镜子：残影引路

P4 的最后一面镜子不只是终点机关，它是“过去终于赶上来之后，开始帮助现在”的转折点。镜子破碎后，残影不再追赶玩家，而是先一步走向真正的终点。

演出顺序：

1. 玩家触发最后一面镜子，镜面裂纹扩散，碎片在空中短暂静止；Bridge 的两拍静音落在碎片完全停住的瞬间。
2. 碎片中的倒影重新聚成一个半透明残影。它比玩家更清晰，边缘带白金与淡蓝光，不再使用 P2 残影的模糊冷蓝效果。
3. 残影沿正确路线提前走出一个转向，在下一个关键节点停下来等待玩家。它不改变玩家位置、不替玩家输入，也不直接把玩家拉到终点。
4. 玩家跟随残影前进。残影始终保持一小段距离，像“未来几秒的动作预演”；玩家偏离时，残影不消失，而是在下一个节点重新停下，继续提供方向。
5. 残影先抵达终点并回头，玩家抵达后触发最后一次“滞后转向”：残影与玩家先后完成同一动作，随后两者向中心汇聚、缩放淡出。
6. 汇聚完成后才出现最终文案：**「迟到的温柔，终于抵达。」**

这段残影必须与 P2 的残影区分：P2 是“过去追赶现在”，冷蓝、模糊、落后于玩家；P4 是“过去为现在指路”，清晰、白金、提前完成动作。玩家看到的不是一个 NPC，而是自己的下一拍。

## 四、视听表现系统

### 4.1 屏幕边缘呼吸光晕
- **安全区**：青蓝微光，缓慢呼吸（1 Hz）
- **警戒区**：金色加速脉动（1–4 Hz），随同步率平滑过渡
- **濒死区**：红金色差分离抖动，呼吸频率最高，配合音乐 8 小节一次的 glitch 失真点同步闪烁

### 4.2 音频动态混音（随同步率实时自动化）
| 音频层 | 变化规则 |
|---|---|
| **主旋律总线** | 低通滤波：截止频率 20kHz → 800Hz（同步率 0%→100%） |
| **心跳层（沙锤轨单独路由）** | 音量：-80 dB → 0 dB（同步率 60% 起渐入，100% 满量） |
| **大提琴 Delay** | 延迟时间：0.3s → 0.6s（同步率 90% 后拉长，制造「追不上」感） |
| **拾取音效（钟琴单音）** | 音高：1.0× → 2.0×（同步率 0%→100%，与 BGM 钟琴同音色） |
| **濒死高通** | 仅 90%+ 开启，截止频率 20Hz → 500Hz，声音变「薄」 |

### 4.3 音乐关键节点触发事件
| 节点 | 音乐事件 | 玩法联动 |
|---|---|---|
| **完整模式 4:10**<br>（原版 Part3 结束→Remix Section D 入场） | 钢琴倒放→正放，钟琴回声密集 | 隐藏段开始，同步率初始化 60%，碎片生成启动 |
| **Remix 每 8 小节** | Glitch 失真打击 | 视觉色差脉冲、同步率UI震动、碎片生成密度微调 |
| **Remix 4:55**<br>碎片门前 | 心跳层独奏，其他乐器淡出 | 玩家被迫冲高同步率，输入震动反馈增强 |
| **Remix 5:00**<br>Bridge 突发静音 | 全轨静音 2 拍 | 画面冻结，同步率锁定，「真正的终点还在更远处」文字淡入 |
| **Remix 5:02**<br>Outro 大提琴独奏 | 仅大提琴 + 自然混响 | 终点汇聚演出，最终文案逐字显现 |

## 五、死亡与结算

| 死亡类型 | 触发条件 | 结算页文案 | 进度影响 |
|---|---|---|---|
| **过度同步** | 同步率 ≥ 100% | 「你追上了过去，却丢失了现在。」<br>—— 重试 / 返回关卡选择 | 不计为通关，完整模式保持「已解锁未通关」 |
| **撞墙/坠落** | 物理碰撞死亡 | 「滞后，也是一种节奏。」 | 同上 |
| **真·通关** | 走完汇聚演出 | **「迟到的温柔，终于抵达。」**<br>显示完整模式耗时、最高同步率、收集率 | 记录 `full_mode_cleared = true`<br>主菜单/关卡选择显示「完整残片」皮肤解锁 |

## 六、关卡制作工作流（编辑器视角）

1. 打开完整模式第 4 段场景
2. 选中主路径 `Path3D` 节点
3. 运行碎片生成工具 → 打开面板：
   - 选择预设密度曲线资源（对应 4 个音乐段落）
   - 设置段落总长 50 秒
   - 点击 **生成** → 自动在路径两侧按曲线密度实例化碎片（作为触发器容器子节点）
4. 微调：手动删减/移动极少数碎片 → 点击 **烘焙** → 碎片转为固定场景实例
5. 运行测试：同步率 HUD 自动显示（调试构建），可实时观察数值曲线与音乐同步情况

## 七、音乐配置规范（LevelData 字段）

| 模式 | LevelData 字段 | 说明 |
|------|----------------|------|
| **分段模式** | `music_mode = "original"`<br>`original_music = "res://#Template/[Music]/Part1.ogg"` | 单段落引用对应原版单曲 |
| **完整模式** | `music_mode = "hybrid"`<br>`original_music = ["Part1.ogg", "Part2.ogg", "Part3.ogg"]`<br>`remix_music = "res://#Template/[Music]/Remix_FullMode.ogg"`<br>`remix_start_offset = 250.0` | 前 250 秒（4:10）顺序播放 3 首原版，**无缝衔接**<br>到达 250 秒 → 淡入 Remix Section D（4:10–5:30） |

**音频资源命名建议：**
```
#Template/[Music]/
├── Part1.ogg          # 段落 1 原版（~90s, 80 BPM）
├── Part2.ogg          # 段落 2 原版（~90s, 100 BPM）
├── Part3.ogg          # 段落 3 原版（~70s, 120 BPM）
└── Remix_FullMode.ogg # 完整模式专用 Remix（5:30，含 Section D + Outro）
```

**衔接逻辑：**
- 原版 3 段用 `AudioStreamInteractive` 或代码队列 `play_track()` 实现**无间隙衔接**（BPM 变化点对齐）
- `remix_start_offset` 到达时：原版淡出 0.5s → Remix 淡入 0.5s，同步率系统同步初始化

## 八、数值验收标准（QA 用）

| 指标 | 目标 | 验收方式 |
|---|---|---|
| **无收集存活时长** | 60% ÷ 1.5% ≈ **40 秒** | 进隐藏段完全不碰碎片，40 秒后同步率降至 0%（不死，仅视觉变暗） |
| **全收集必死验证** | 碎片总数 × 8% - 衰减 ≈ **必死** | 全拾取路线跑，确认 45–50s 必经门前同步率 ≥ 95% |
| **标准通关同步率峰值** | 95% – 99% | 正常技巧通关录像回放，记录最高同步率 |
| **碎片门强制同步率** | 进入门时 95% ± 2% | 门前 3 个碎片为必经，间距固定，数学验证 |
| **性能** | 碎片 100+ 实例时 ≤ 1ms GPU | Profiler 测量 |

## 十、主题隐喻完整性检查

| 机制 | 对应「滞后」主题 |
|---|---|
| **同步率自然衰减** | 时间在拉大你与过去的距离——不主动连接，滞后只会变大 |
| **收集回声碎片回升同步率** | 主动拥抱回声/记忆，让它们追上来 |
| **同步率 100% 死亡** | 完全追上过去 = 被过去吞噬 = 失去「当下的自己」 |
| **健康区间 60%–90%** | 保持「滞后 3 秒的并肩」——既不脱节，也不重合 |
| **最后一面镜子破碎** | 过去不再作为障碍追赶，而是转化为通往终点的方向 |
| **终点强制 99% 汇聚** | 最后一刻允许「几乎同步」，但保留 1% 滞后 = 留有余地的完整 |
| **最终文案「迟到的温柔，终于抵达」** | 滞后的温柔不是「从未迟到」，而是「即使迟到，依然抵达」 |
