### 段落 1：初滞（The World Slows）

| 元素       | 设计                                                                            |
| -------- | ----------------------------------------------------------------------------- |
| **场景**   | 暖黄+深蓝峡谷通道，深蓝色块状平台夹住路径两侧，远景散布灰色/棕色立方体柱子营造天际线                                   |
| **音乐**   | 钢琴独奏，节奏缓慢， BPM 约 80                                                           |
| **核心机制** | 正常操作，但**每 8 拍有一次「卡顿」**——线条突然减速 0.5 秒，音乐也轻微失真                                  |
| **视觉**   | 极简Low-Poly几何风格，天空与地面暖黄调融为一体带轻微雾效；路径附近淡蓝色小碎片/光点飘浮；卡顿瞬间画面出现轻微 RGB 分离（glitch 效果） |
| **叙事**   | 开场文字：「世界开始变慢，你还没意识到。」                                                         |
|          |                                                                               |

#### 新手引导设计

| 阶段            | 引导方式                 | 教学内容             | 故事融合                   |
| ------------- | -------------------- | ---------------- | ---------------------- |
| **起始（0-15秒）** | 路径自动延伸，无需操作          | 观察世界，感受氛围        | 机器人醒来，视线从模糊到清晰         |
| **初次转向**      | 路径出现明显分岔，左侧有柔和光晕提示   | 点击屏幕左/右半区转向      | 「你试着移动——身体比意识慢了一拍。」    |
| **节奏感建立**     | 路径节点随钢琴节拍闪烁，错过不影响前进  | 跟随节奏点击可获得连击加成    | 「跟着这个世界的脉搏，慢慢来。」       |
| **第一次卡顿**     | 强制触发，画面冻结，出现文字提示     | 理解卡顿机制：世界会定期「脱节」 | 「它停下来了。不是故障，是这个世界在呼吸。」 |
| **卡顿适应**      | 连续3次卡顿，每次间隔缩短，引导玩家预判 | 学会在卡顿前调整方向       | 「你开始习惯它的节奏——滞后，但可预测。」  |
| **段落结束**      | 路径收窄，雾气加重，远景出现山谷轮廓   | 准备进入段落2          | 「前方的路，似乎有另一个你在等待。」     |

#### 引导原则
- **不打断沉浸**：所有提示以「叙事文字」形式出现，而非传统UI教程
- **允许失败**：前30秒内撞墙不会死亡，线条自动修正方向
- **渐进式难度**：转向角度从30°→45°→60°逐步增加
- **卡顿预兆**：每次卡顿前0.5秒，画面边缘出现轻微扭曲，给玩家反应时间

### 段落 2：回声（The Echo Catches Up）

| 元素 | 设计 |
|---|---|
| **场景** | 转入山谷，色调变暗，雾气加重 |
| **音乐** | 加入弦乐，BPM 提升至 100，旋律与段落 1 呼应但更丰富 |
| **核心机制** | 路径上出现**半透明残影**——这是 3 秒前的你。残影走过的路径是安全的，但偏离残影可能撞墙 |
| **视觉** | 残影带拖尾粒子，颜色偏淡蓝；背景偶尔闪过段落 1 的场景碎片 |
| **叙事** | 中段文字：「那些你以为已经过去的，正在追上你。」 |
