# UI 文字汇总

## 游戏命名

- **中文名：《弄影》** — 取自苏轼《水调歌头》「起舞弄清影，何似在人间」。玩家操控线条起舞，残影永远慢半拍相随（弄影），含蓄点出「滞后」主题。
- **英文名：AFTERIMAGE**
- 应用名：弄影 Afterimage

- **品牌标题（BrandTitle）**：「弄影」/「AFTERIMAGE」

## 开场白

> BoomBit 的《Through The Fog》里，有一关叫 _Peaceful Stagnation_。 停滞，但宁静。
> 现在，我们用 Godot 把它重新讲成一个关于**滞后**的故事。
> 你控制一条线。 它本该随你指尖即刻转向—— 但在这个世界里，点击之后，要等一等。
> 等 0.3 秒。 等一个节拍。 等那个**滞后的自己**，从身后追上来。
> 行动滞后于意志， 记忆滞后于时光， 温柔滞后于错过。
> 穿过那扇发光的拱门， 你以为已经抵达。
> 但真正的答案—— 还在更远处。
> 跟紧那个迟到的回声。 它知道真正的路。

## 段落叙事文字

### 段落 1：初滞

- **开场**：「世界开始变慢，你还没意识到。」
- **新手引导**：
  - 「你试着移动——身体比意识慢了一拍。」
  - 「跟着这个世界的脉搏，慢慢来。」
  - 「它停下来了。不是故障，是这个世界在呼吸。」
  - 「你开始习惯它的节奏——滞后，但可预测。」
  - 「前方的路，似乎有另一个你在等待。」

### 段落 2：回声

- **中段**：「那些你以为已经过去的，正在追上你。」

### 段落 3：终章

- **结尾**：「你以为已经抵达……」
- **假终点提示**：「真正的终点，还在更远处。」

### 同步率玩法介绍（Part 2 / Part 3 开始前，非全屏卡片）

- **标题**：「同步率」/「SYNC RATE」
- **正文**：「跟着节奏点击转向，保持同步率不耗尽。同步率会随时间衰减；收集水晶与皇冠、穿过回响拱门可恢复。同步率越低，节奏越慢；耗尽即失败。」
- **提示**：「点击任意处关闭」

## 完整模式（完整关卡）

- **最终文字**：「迟到的温柔，终于抵达。」

## 多结局（完整关卡按最终同步率分层）

| 条件 | 标题（中/英） |
|---|---|
| 最终同步率 ≥90% 且 part3 曾 100% | 完美同步 / PERFECT SYNC |
| ≥90% | 心意相通 / HEARTS CONNECTED |
| ≥60% | 渐入佳境 / GROWING RHYTHM |
| ≥30% | 迟来的抵达 / A LATE ARRIVAL |
| <30% | 残存的微光 / A FADING LIGHT |

- part3（终章）通关时同步率 ≥99.5% 会写入 `[endings] part3_perfect_sync = true`，作为完整关卡最高档结局的前置条件。
- 结局只在完整关卡（第 4 槽位）显示，Part 1–3 通关显示各自段落文案。
