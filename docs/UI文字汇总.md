- **英文名：AFTERIMAGE**
- 应用名：弄影 Afterimage

## 开场白

> BoomBit 的《Through The Fog》里，有一关叫 _Peaceful Stagnation_。 停滞，但宁静。
> 现在，我们用 Godot 把它重新讲成一个关于**滞后**的故事。
> 你控制一条线。 它本该随你指尖即刻转向—— 但在这个世界里，点击之后，要等一等。
> 等 0.3 秒。 等一个节拍。 等那个**滞后的自己**，从身后追上来。
> 行动滞后于意志， 记忆滞后于时光， 温柔滞后于错过。
> 穿过那扇发光的拱门， 你以为已经抵达。
> 但真正的答案—— 还在更远处。
> 跟紧那个迟到的回声。 它知道真正的路。

## 完整模式（完整关卡）

- **最终文字**：「迟到的温柔，终于抵达。」

## 多结局（完整关卡）

完整关卡无同步率系统，结局基础档位按 **part3（终章）结束同步率** 分层（part3 实际可达上限约 70%，70 为完美线）；完整关卡内每满 2 次死亡降 1 档，累计 8 次触发坏结局。

| 条件 | 标题（中/英） |
|---|---|
| part2 ≥98% 且 part3 ≥70% | 完美同步 ✨ / PERFECT SYNC |
| part3 ≥60% | 心意相通 💞 / HEARTS CONNECTED |
| part3 ≥45% | 渐入佳境 🌄 / GROWING RHYTHM |
| part3 ≥30% | 迟来的抵达 🌆 / A LATE ARRIVAL |
| part3 <30% | 残存的微光 🕯️ / A FADING LIGHT |
| 完整关卡累计死亡 8 次 | **坏结局：微光熄灭 😭 / THE LIGHT GOES OUT** |

- 死亡降档：完整关卡内每满 2 次死亡降 1 档（最低「残存的微光」）；计数跨重开/复活保留，从主菜单再次进入时清零。
- **坏结局文案**：序数标签「坏结局 / BAD ENDING」+ 标题「微光熄灭 😭 / THE LIGHT GOES OUT 😭」；正文「八次跌倒之后，残影终于不再追赶，只是站在原地，目送你远去。回声之境的门缓缓合拢——门没有上锁，想回来时，它依然为你敞开。🌫️」；诗句「无可奈何花落去，似曾相识燕归来。」—— 晏殊《浣溪沙》。画面提供「重新开始 / 返回主菜单」，不写入任何进度。
- 死亡/复活结算页共用提示「已跌倒 N/8，残影依然在等你 🌫️」。
- 结局只在完整关卡（第 4 槽位）显示，Part 1–3 通关显示各自段落文案。

## 结算报幕（完整关卡结尾）

滚动段（自下而上匀速滚动）：
- **主题句**：「有些答案，总在错过之后才抵达。」
- **李商隐《锦瑟》**：「此情可待成追忆，只是当时已惘然。」—— 出处：「李商隐《锦瑟》」
- **致谢**：「感谢游玩」—— meny233
- **灵感来源**：「Dancing Line · Through the Fog · DLMTP」

定格段（滚动结束后的停驻画面，「属于你的回声」）：
- 「属于你的回声」+ **结局序数**（好结局一 ~ 好结局五）+ **结局名**（五档之一，含 emoji）
- **结局诗**（随结局切换）+ 出处：
  - 完美同步 ✨ → 起舞弄清影，何似在人间。——苏轼《水调歌头》
  - 心意相通 💞 → 永结无情游，相期邈云汉。——李白《月下独酌》
  - 渐入佳境 🌄 → 行到水穷处，坐看云起时。——王维《终南别业》
  - 迟来的抵达 🌆 → 此情可待成追忆，只是当时已惘然。——李商隐《锦瑟》
  - 残存的微光 🕯️ → 留得残荷听雨声。——李商隐《宿骆氏亭寄怀崔雍崔衮》
- 标题「弄影」/「AFTERIMAGE」+「终」+「返回主菜单」

> **去重规则**：滚动段仅保留锦瑟句；若与定格结局诗相同（迟来的抵达），滚动段跳过该句，由定格展示。苏轼、李白句只作为对应结局的定格结局诗出现，不在滚动段重复。

## 一句话梗概

> **一个小 Godot 机器人在「滞后」的世界里，发现追赶自己的残影不是敌人，而是迟到的温柔——当它不再逃避，与过去并肩，真正的终点才终于抵达。**
