# 弄影 Afterimage — 参赛项目介绍

> **主题**：滞后 / Delay  
> **立意**：有些回声姗姗来迟，有些答案总在错过之后才抵达。当行动、情感、记忆或世界本身发生"滞后"，会诞生怎样的机制和故事？捕捉那些迟到的温柔与回响！

---

## 一、项目概览

| 项目 | 内容 |
|------|------|
| **名称** | 弄影 Afterimage（中文《弄影》/ 英文 AFTERIMAGE） |
| **引擎** | Godot 4.7 |
| **平台** | Web（优先）+ Windows |
| **类型** | 3D 节奏线控跑酷 |
| **核心机制** | 玩家控制一条线沿路径前进，跟随音乐节奏点击转向，在「滞后」的世界里体验行动、记忆与情感的延迟与回响 |
| **关卡结构** | 三段落 + 隐藏第四段「回声之境」，段落解锁 + 完整模式 |
| **主题** | 滞后 Delay——行动滞后于意志，记忆滞后于时光，温柔滞后于错过 |

## 二、核心玩法：滞后即机制

### 基础操作

点击屏幕 / 空格键控制线条转向，跟随音乐节拍沿路径前进。操作简单，单手可玩，但每一次点击都需要**预判**——因为在这个世界里，输入之后，要等一等。

### 四层滞后机制，层层递进

| 机制 | 说明 | 出现段落 | 主题对应 |
|------|------|----------|----------|
| **延迟响应** | 点击后 0.3 秒线条才转向，玩家必须预判节拍 | P1 后期、P3 | 行动滞后于意志 |
| **卡顿判定** | 每 8 拍世界冻结 0.5 秒，画面 RGB 分离、音频失真 | P1 | 世界本身的滞后 |
| **残影跟随** | 一个半透明「过去的自己」慢 3 秒重复玩家动作，残影走过的路是安全的 | P2 | 记忆滞后于当下 |
| **同步率系统** | 同步率随游玩自然衰减，映射到全局时间速度（0.8~1.1）与音乐音高——玩家越落后，世界越慢，音乐越沉 | P4（隐藏段） | 全世界都在等你 |

### 同步率博弈（P4 核心玩法创新）

> 同步率 ≠ 血量。同步率越高越危险。

- 数值范围 0%~100%，初始 60%，自然衰减 1.5%/秒
- 收集「回声碎片」回升同步率（+8%/个）
- **同步率 100% 即死**——"你追上了过去，却丢失了现在"
- 健康区间 60%~90%，保持"3 秒滞后的并肩"才是通关之道
- 同步率低时世界变慢（`Engine.time_scale` 降至 0.8），音乐低沉；濒死时红金色差抖动、心跳声叠加、强制慢动作

**机制即主题**：在这个世界里，"滞后"不是抽象概念，是可感知的物理规则——你每慢一拍，整个世界都在等你。

### 假终点结构（叙事与玩法双重创新）

P3 穿过发光拱门后，屏幕渐白、音乐戛然而止，文字浮现——"你以为已经抵达。"然后结算页显示"完整模式已解锁"。玩家必须**亲自经历一次"错过"**，解锁完整模式，才能进入真正的终点（P4 回声之境）。

**结构即主题**：答案不会在第一次到来——"有些答案，总在错过之后才抵达。"

## 三、UI 与交互设计：完整流畅的玩家旅程

### 完整流程闭环

```
[启动画面] → [主菜单] → [关卡选择] → [段落选择/完整模式] → [游戏内 HUD] → [结算页] → [重试/返回]
```

### 各界面设计要点

| 界面 | 功能与设计亮点 |
|------|---------------|
| **主菜单** | 背景程序化绘制四条渐隐尾迹回声线，将"滞后"主菜单即视觉化；标题「弄影 / AFTERIMAGE」；主标题「追上那个迟到的自己」 |
| **关卡选择** | 四张卡片横向排列（初滞/回声/终章/回声之境），未解锁显示锁图标+模糊预览；卡片切换带镜面轮盘动画，封面背景随槽位变换色调 |
| **设置面板** | 音量、音画延迟（±10ms 三角按钮步进，±5000ms 范围）、**转向键键位录制**（点击后按任意键绑定，持久化到 settings.cfg）、语言、抗锯齿、画质 |
| **游戏内 HUD** | 顶部进度条、右上角同步率胶囊进度条（竖向，跟随同步率区间变色）、极简设计不干扰沉浸 |
| **结算页** | 完成度%、评级（S/A/B/C）、段落主题文字、解锁提示；完整模式按最终同步率分五档结局（完美同步/心意相通/渐入佳境/迟来的抵达/残存的微光） |
| **暂停菜单** | 继续、重试、返回关卡选择、设置 |
| **皮肤面板** | 经典 / Godot 低多边形双皮肤选择，带转弯/滑铲动画预览 |

### 交互完整性

- 完整的设置面板（音量、延迟校准、键位录制、画质、语言）
- 多结局系统（5 档结局，按最终同步率分层）
- 进度持久化（关卡解锁状态、皮肤解锁、结局记录写入 `user://settings.cfg`）
- 主菜单与游戏内设置双入口，操作一致
- 完整的退出/重试/保存/重新加载流程

## 四、场景与美术设计：心象路径的视觉化

### 低多边形 + 风格化渲染，四段色调递进

整个游戏是一座**心灵地图**——机器人走过的四个场景，不是随机地图设计，而是穿越"滞后"概念本身的四个维度。

| 段落 | 场景 | 色调 | 方向 | 心理状态 | 核心视觉元素 |
|------|------|------|------|----------|-------------|
| **P1 初滞** | 暖黄峡谷 | 暖黄 + 深蓝 | 向外看 | 好奇、观察 | 立方体柱子天际线、淡蓝漂浮碎片、卡顿时 RGB 分离/体积光轴放大 |
| **P2 回声** | 灰蓝山谷 | 灰蓝 + 暗紫 | 向后看 | 恐惧、信任 | 浓雾（指数平方雾）、残影淡蓝拖尾粒子、山谷回音壁结构 |
| **P3 终章** | 破晓拱门 | 暗→微光破晓 | 向前看 | 期待、误以为抵达 | Bloom 强度 0.6→1.8、强体积光束"上帝之光"、拱门金光流淌 |
| **P4 回声之境** | 镜面回廊 | 全亮 + 镜面 | 向下看 | 接纳、释然 | 破碎镜面地面（SSR）、三段残影同屏、同步率联动边缘光晕（青蓝→金→红金） |

### Shader 与特效（风格化加分项）

| 效果 | 用途 |
|------|------|
| **RGB 分离（Chromatic Aberration）** | 卡顿瞬间、同步率濒死区 |
| **雾效（Fog）** | 线性雾 P1/P3、指数平方雾 P2、无雾 P4 |
| **残影拖尾（Trail/Afterimage）** | P2 核心视觉，淡蓝粒子随音乐脉动 |
| **Bloom 辉光** | P3 拱门光芒溢出、P4 终点汇聚 |
| **屏幕空间反射（SSR）** | P4 镜面地面，菲涅尔 0.3 |
| **同步率联动光晕** | 安全区青蓝→警戒区金→濒死区红金色差抖动 |

### 场景即心象：四个场景的情感递进

```
暖黄峡谷        灰蓝山谷        破晓拱门        回声之境
  ↓               ↓               ↓               ↓
发现"滞后" →  被"滞后"追赶 → 误以为理解 → 接纳"滞后"
  ↓               ↓               ↓               ↓
 平静           紧张            怅然            释然
```

## 五、音乐与音效：音乐即世界

### 音乐结构

- **风格**：钢琴 + 弦乐 + 电子氛围音
- **三段一体**：同一主题动机，逐层叠加，终章完整呈现
- **BPM 递进**：80 → 100 → 120，形成情绪递进
- **完整模式 Remix**：前三段原版无缝衔接，隐藏段切 Remix（含倒放钢琴 + 回声交织）

### 同步率联动音频（技术创新）

- 音乐音高随同步率实时变化——玩家体验到的不是"音乐变慢了"，而是"整个世界连同音乐一起慢下来"
- 低通滤波随同步率自动调节（截止频率 20kHz → 800Hz）
- 心跳层在同步率 60% 起渐入，濒死区声音变薄变尖锐
- 拾取碎片时钢琴泛音，音高随同步率升高

### 音效设计

| 事件 | 音效 | 主题对应 |
|------|------|----------|
| 点击转向 | 清脆钢琴单音（与 BGM 和弦匹配） | 意志触发行动 |
| 错过节拍 | 低沉嗡声 + 轻微失真 | 滞后被感知 |
| 卡顿 | 低频失真 + 环境抽空 | 时间脱节 |
| 碎片拾取 | 钢琴泛音，音高随同步率上升 | 回声被接纳 |
| 残影出现 | 微弱回声混响 | 记忆追赶 |
| 通关 | 主题完整奏响 + 混响 5 秒衰减 | 迟到的温柔抵达 |

## 六、主题契合度：滞后的四个维度

| 维度 | 游戏内表现 | 叙事体现 |
|------|-----------|----------|
| **行动滞后** | 点击后 0.3 秒延迟转向、音画延迟可调参数 | 「你试着移动——身体比意识慢了一拍」 |
| **记忆滞后** | P2 残影慢 3 秒跟随，走过的路安全 | 「那些你以为已经过去的，正在追上你」 |
| **情感滞后** | 假结局后的怅然 → 片尾释然 | 「迟到的温柔，终于抵达」 |
| **世界滞后** | 同步率系统、卡顿呼吸、时间缩放 | 「不是故障，是这个世界在呼吸」 |

**本作不把滞后表现为惩罚性的"卡顿"或"故障"，而是把它表现为一种需要被看见、被接纳、最终与之共存的节奏。** 玩家最终学会的，不是消灭滞后，而是等待那个迟到的自己——与过去的你，并肩走向终点。

- ✅ **主题契合度：高（×1）**——滞后不是包装，是可玩、可感、可共鸣的核心机制

### 游戏玩法（30%）

- ✅ **创新性**：同步率博弈（非血量、非计时，高同步率即死）、残影引路（3 秒延迟的"过去的自己"保护现在）、假终点解锁结构
- ✅ **趣味性**：预判 0.3 秒延迟的独特手感、跟随残影的信任感探索、同步率濒死区的紧张博弈
- ✅ **挑战性**：同步率衰减与收集的数值博弈、卡顿预判、残影路径选择；操作简单（点击转向）但深度充足

- ✅ **风格统一**：低多边形 + 风格化渲染，四段色调递进（暖黄→灰蓝→破晓→全亮镜面）
- ✅ **Shader 使用**：RGB 分离、Bloom、SSR、雾效、残影拖尾粒子、同步率联动光晕
- ✅ **UI 统一性**：镜面碎边轮盘选关、四段色调一致的卡片封面、极简 HUD

### 音乐与音效（10%）

- ✅ **音乐风格匹配**：钢琴 + 弦乐 + 电子氛围，三段主题动机递进
- ✅ **创新联动**：同步率影响音乐音高/滤波/心跳层，实时沉浸交互
- ✅ **音效设计**：每项交互对应主题音效（钢琴单音=意志触发、回声混响=记忆追赶）

### 稳定性与优化（10%）

- ✅ **Jolt Physics 独立线程**，物理计算稳定
- ✅ **对象池复用**（Player 尾迹 256 MeshInstance3D）
- ✅ **CanvasLayer 层级管理**（皮肤 41 / 同步率 HUD 40 / 玩法介绍 90 / 片头 128），避免 UI 冲突
- ✅ **路径碎片程序化生成**，非手动摆放，可烘焙固定

### 加分项（10%）

- ✅ **情绪调动**：完整情感曲线（平静→好奇→紧张→期待→怅然→释然→温柔），通过四段色调递进、音乐叠加、叙事文字逐层推进
- ✅ **叙事创新**：假终点结构让玩家亲身"错过"一次，再解锁真结局，将"迟到的答案"从文字变为体验
- ✅ **主题深度**：融合李商隐"此情可待成追忆"的古典诗意与现代游戏机制，滞后不是缺陷，而是被接纳的温柔
- ✅ **片尾情感落点**：最终文案「迟到的温柔，终于抵达」+ 李商隐诗句 + 主题注解，三重情感叠加

## 八、核心文案

### 开场白

> BoomBit 的《Through The Fog》里，有一关叫 _Peaceful Stagnation_。停滞，但宁静。
> 现在，我们用 Godot 把它重新讲成一个关于**滞后**的故事。
> 你控制一条线。它本该随你指尖即刻转向——但在这个世界里，点击之后，要等一等。
> 等 0.3 秒。等一个节拍。等那个**滞后的自己**，从身后追上来。
> 行动滞后于意志，记忆滞后于时光，温柔滞后于错过。
> 穿过那扇发光的拱门，你以为已经抵达。
> 但真正的答案——还在更远处。
> 跟紧那个迟到的回声。它知道真正的路。

### 主线叙事文字

| 段落 | 文字 |
|------|------|
| P1 初滞 | 「世界开始变慢，你还没意识到。」|
| P1 首次转向 | 「你试着移动——身体比意识慢了一拍。」|
| P1 卡顿 | 「它停下来了。不是故障，是这个世界在呼吸。」|
| P1 → P2 | 「前方的路，似乎有另一个你在等待。」|
| P2 残影出现 | 「那些你以为已经过去的，正在追上你。」|
| P3 假终点 | 「你以为已经抵达……」→「真正的终点，还在更远处。」|
| P3 结算 | 「有些答案，总在错过之后才抵达。」|
| P4 终点 | **「迟到的温柔，终于抵达。」**|

### 一句话梗概

> 一个小 Godot 机器人在「滞后」的世界里，发现追赶自己的残影不是敌人，而是迟到的温柔——当它不再逃避，与过去并肩，真正的终点才终于抵达。

## 九、技术实现亮点
