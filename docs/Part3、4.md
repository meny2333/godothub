
## 三、关卡分段设计（更新版）

### 段落 3：终章（The Gentle Arrival）— 假终点版

| 元素       | 设计                                                         |
| -------- | ---------------------------------------------------------- |
| **场景**   | 山谷尽头，天空微亮，阳光穿透云层，前方出现一座发光的拱门                               |
| **音乐**   | 全乐器进入，旋律推向高潮，仿佛即将结束                                        |
| **核心机制** | 全程慢速播放，最后 20% 速度恢复正常，音乐达到顶点                                |
| **视觉**   | 暗色调 → 微光破晓；终点拱门光芒越来越盛                                      |
| **叙事**   | 结尾文字：「你以为已经抵达……」                                           |
| **假终点**  | 线条穿过拱门时先做一次机车式滑步过弯般的滞后转向，随后屏幕渐白，音乐戛然而止，弹出提示：「真正的终点，还在更远处。」 |

**解锁提示**：通关假终点后，结算页显示「完整模式已解锁」，并附文字：「有些答案，总在错过之后才抵达。」

### 完整模式：真正的终章（The True Arrival）

| 元素 | 设计 |
|---|---|
| **解锁条件** | 通关段落 3 的假终点 |
| **内容** | 3 段连跑 + **假终点后的隐藏第四段** |
| **隐藏第四段** | 穿过拱门后，场景并未结束——线条继续向前，进入一片更开阔的「回声之境」： |
| | • 场景：天空完全亮起，但地面是破碎的镜面，反射出段落 1~3 的残影 |
| | • 音乐：段落 1 的钢琴主题以极慢速倒放，然后正放，形成「回声」 |
| | • 机制：路径上同时出现「过去的自己」（段落 1~3 的残影）和「现在的自己」，需要跟随残影穿越镜面 |
| | • 终点：线条与所有残影在最后一次滞后转向中汇聚成一点，然后消散，屏幕出现最终文字：「迟到的温柔，终于抵达。」 |
| **时长** | 隐藏段约 40~60 秒，完整模式总时长约 5~6 分钟 |

---

## 「假终点」机制的主题契合

| 设计 | 对应「滞后」主题 |
|---|---|
| **假终点制造「错过」** | 玩家以为已经抵达，实际只是半程——对应「有些答案总在错过之后才抵达」 |
| **解锁后才能看到真终点** | 真正的答案被「延迟」释放，必须经历一次「错过」才能理解 |
| **隐藏段的回声之境** | 所有过去的段落以残影形式重现，并在终点前完成一次滞后转向的收束——对应「回声姗姗来迟」 |
| **最终文字** | 与段落 3 假终点的文字形成呼应，完成情感闭环 |

## 技术实现要点（新增）

| 机制 | 实现方案 |
|---|---|
| **假终点触发** | 段落 3 的 `PathFollow3D` 到达 100% 时，不直接结算，而是播放过场动画（拱门穿越 → 滞后转向 → 渐白 → 提示文字） |
| **隐藏第四段** | 完整模式中，前 3 段用 `change_scene_to_file()` 无缝衔接；第 4 段作为独立 Scene，在假终点位置动态加载 |
| **残影汇聚** | 第 4 段终点前，用 `Tween` 将所有残影节点向中心点移动，同时缩小并提高透明度，最后同时消失 |
| **解锁状态** | `ConfigFile` 记录 `full_mode_unlocked = true`，关卡选择界面读取后切换卡片状态 |
