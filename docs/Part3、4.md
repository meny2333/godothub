
## 三、关卡分段设计（更新版）

### 段落 3：终章（The Gentle Arrival）— 假终点版

| 元素       | 设计                                                         |
| -------- | ---------------------------------------------------------- |
| **场景**   | 山谷尽头，天空微亮，阳光穿透云层，前方出现一座发光的拱门                               |
| **音乐**   | 全乐器进入，旋律推向高潮，仿佛即将结束                                        |
| **核心机制** | 全程慢速播放，最后 20% 速度恢复正常，音乐达到顶点                                |
| **视觉**   | 暗色调 → 微光破晓；终点拱门光芒越来越盛                                      |
| **开场文字** | 「雾正在散去，前方的发光拱门像是出口。穿过它，看看微光把你带向哪里。」 |
| **叙事**   | 结尾文字：「你以为已经抵达……」                                           |
| **假终点**  | 线条穿过拱门时先做一次机车式滑步过弯般的滞后转向，随后屏幕渐白，音乐戛然而止，弹出提示：「真正的终点，还在更远处。」 |

**解锁提示**：通关假终点后，结算页显示「完整模式已解锁」，并附文字：「有些答案，总在错过之后才抵达。」

### 完整模式：真正的终章（The True Arrival）

| 元素 | 设计 |
|---|---|
| **解锁条件** | 通关段落 3 的假终点 |
| **内容** | 3 段连跑 + **假终点后的隐藏第四段** |
| **隐藏第四段** | 穿过拱门后，场景并未结束——线条继续向前，进入一片更开阔的「回声之境」： |
| | • 场景：天空完全亮起，但地面是破碎的镜面，反射出段落 1~3 的残影 |
| | • 音乐：前半段以段落 1 的钢琴主题极慢速倒放，保持稀疏、平静的环境声；机器人第一次与残影完成同步时，音乐短暂抽空两拍，随后逐层加入鼓组、弦乐与电子节奏，后半段进入燃烧般的推进段，形成「从理解世界到主动回应世界」的情绪转折 |
| | • 机制：路径上同时出现「过去的自己」（段落 1~3 的残影）和「现在的自己」，需要跟随残影穿越镜面 |
| | • 末段机制：最后一面镜子破碎后，碎片中的倒影聚成一个清晰的白金淡蓝残影；残影提前走出下一个转向，在关键节点停下等待玩家，引导玩家走向真正的终点 |
| | • 终点：残影先抵达并回头，玩家随后到达；两者在最后一次滞后转向中汇聚成一点，然后消散，屏幕出现最终文字：「迟到的温柔，终于抵达。」 |
| **时长** | 隐藏段约 40~60 秒，完整模式总时长约 5~6 分钟 |

**开场文字**：「拱门之后并非终点。破碎镜面映出所有未走的路；跟随残影，穿过回声之境。」

#### P4 音乐转折：从观察到回应

P4 前半段的平静不是高潮前的空白，而是 Godot 机器人刚接触这个世界时的陌生、观察与迟疑。它还在确认残影究竟是敌人、记忆，还是另一个自己。

音乐转折必须绑定明确的叙事事件：当机器人第一次与残影完成同一个转向，或第一面镜子在两者同步后破碎，音乐先抽空两拍，只留下回声尾音；随后在 4~8 小节内逐层加入低频鼓组、弦乐和电子节拍，避免像突然切换到另一首曲子。

后半段的燃烧感不表示战斗开始，而表示机器人终于接受残影，并从被动观察者变成主动前进者。对应的玩法也应同步升级：路径转弯频率增加，残影开始提前走出关键转向，玩家需要在更强的节奏推动下主动跟随，而不是被音乐单方面催促。

---

### P4 末段：镜中残影引路

最后一面镜子的破碎是 P4 的情感转折，而不是单纯的视觉爆点。前面的残影代表过去在追赶现在；镜子破碎之后，过去终于晚到一步，却反过来给现在指路。

| 阶段 | 画面与动作 | 玩家感受 |
|---|---|---|
| 镜面停滞 | 裂纹扩散，碎片在空中停住，Bridge 两拍静音 | 世界暂时失去时间流动 |
| 残影成形 | 碎片倒影聚成清晰的白金淡蓝残影 | 过去没有消失，而是留下来帮助玩家 |
| 提前转向 | 残影先走过一个关键转弯，到节点后停下等待 | 看见“下一拍”的自己 |
| 跟随前进 | 玩家自主完成转向，残影始终保持一小段距离 | 方向被照亮，但选择仍属于玩家 |
| 终点汇聚 | 残影先抵达并回头，玩家到达后完成同一滞后转向 | 过去与现在终于保持距离地重合 |

残影不能直接牵引玩家、替玩家触发输入或瞬移玩家。它的功能是给出下一步的视觉预演，并在玩家偏离时于下一个关键节点重新等待。这样才能保留“引导”与“滞后”之间的张力。

## 「假终点」机制的主题契合

| 设计 | 对应「滞后」主题 |
|---|---|
| **假终点制造「错过」** | 玩家以为已经抵达，实际只是半程——对应「有些答案总在错过之后才抵达」 |
| **解锁后才能看到真终点** | 真正的答案被「延迟」释放，必须经历一次「错过」才能理解 |
| **隐藏段的回声之境** | 所有过去的段落以残影形式重现，并在终点前完成一次滞后转向的收束——对应「回声姗姗来迟」 |
| **最后一面镜子破碎** | 过去从追赶者变成引路者，滞后不再是阻碍而是方向 |
| **最终文字** | 与段落 3 假终点的文字形成呼应，完成情感闭环 |

## 技术实现要点（新增）

| 机制 | 实现方案 |
|---|---|
| **假终点触发** | 段落 3 的 `PathFollow3D` 到达 100% 时，不直接结算，而是播放过场动画（拱门穿越 → 滞后转向 → 渐白 → 提示文字） |
| **隐藏第四段** | 完整模式中，前 3 段用 `change_scene_to_file()` 无缝衔接；第 4 段作为独立 Scene，在假终点位置动态加载 |
| **残影汇聚** | 第 4 段终点前，用 `Tween` 将所有残影节点向中心点移动，同时缩小并提高透明度，最后同时消失 |
| **解锁状态** | `ConfigFile` 记录 `full_mode_unlocked = true`，关卡选择界面读取后切换卡片状态 |
