## 角色设计建议

### 基础形象

- **原型**：Godot 引擎图标的小机器人（齿轮头、圆眼睛）
- **体型**：简化 Q 版，低多边形风格，与场景统一
- **颜色**：默认蓝灰色，随段落变化（见下方）

### 三段落的视觉变化

| 段落 | 角色状态 | 视觉表现 |
|---|---|---|
| **初滞** | 正常，但偶尔「卡顿」 | 行走时突然定格 0.3 秒，身体轻微 RGB 分离 |
| **回声** | 身后跟随半透明残影 | 残影是 3 秒前的自己，表情更迷茫 |
| **终章** | 与残影并肩 | 残影逐渐清晰，最终与自己融合，颜色从暗转亮 |

### 动作设计

- **移动**：小跑/漂浮，而非滑动——更有「追赶」感
- **转向**：像机车过弯一样先压重心、再顺势滑步转向，脚步比身体晚半拍跟上（机制可视化）
- **碰撞**：被障碍物绊倒/弹开，而非线条断裂
- **假终点**：穿过拱门时先做一次滞后转向，像要回头确认什么，然后再消散

## 技术实现（Godot）

| 模块 | 方案 |
|---|---|
| **模型** | 低多边形角色，用 Blender 做或找 CC0 资源改 |
| **动画** | `AnimationPlayer` 做跑/停/转向/消散动画 |
| **残影** | 每隔固定帧复制角色 Mesh，降低透明度，播放淡出 |
| **卡顿** | 临时冻结 `AnimationPlayer`，同时 Shader RGB 分离 |
| **颜色变化** | 用 `ShaderMaterial` 的 uniform 控制色调，段落切换时渐变 |

## 与「回声残片」皮肤系统的结合

如果做皮肤系统，可以设计：

| 皮肤名 | 外观 | 解锁条件 |
|---|---|---|
| **默认：小 Godot** | 蓝灰色齿轮头 | 初始 |
| **初滞残片** | 身体带轻微 glitch 条纹 | 通关段落 1 |
| **回声残片** | 身后常驻淡影 | 通关段落 2 |
| **终章残片** | 微光环绕，终点前爆发 | 通关段落 3 |
| **完整残片** | 三者叠加，金色轮廓 | 通关完整模式 |

## 风险提醒

| 风险       | 备案                                    |
| -------- | ------------------------------------- |
| 角色模型制作耗时 | 如果来不及，用**极简几何体**（方块头+圆柱身）也能表达 Godot 感 |
| 动画工作量    | 先做**跑+停+转向**三个基础动画，其他用代码补             |
| 与场景比例失调  | 角色高度控制在场景宽度的 1/5 以内，保持 DL 的「小而精致」感    |
