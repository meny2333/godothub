## 一、整体关卡流程概览

| 阶段 | 场景 | 时长 | BPM | 核心机制 | 叙事核心 | 解锁条件 |
|------|------|------|-----|----------|----------|----------|
| **P1 初滞** | 暖黄峡谷 | ~90s | 80 | 卡顿判定、延迟响应预判 | 世界变慢，你未察觉 | 初始解锁 |
| **P2 回声** | 灰蓝山谷 | ~120s | 100 | 残影跟随（3秒延迟）、安全路径提示 | 以为过去的，正在追上你 | 通关 P1 |
| **P3 终章·假终点** | 破晓拱门 | ~90s | 120 | 全程慢速、最后 20% 恢复正速、假终点演出 | 你以为已经抵达…… | 通关 P2 |
| **P4 回声之境（隐藏）** | 镜面回廊 | ~50s | 80 (Remix) | **同步率博弈**——收集回声碎片↑同步率，自然衰减↓同步率，100% 即死 | 迟到的温柔，终于抵达 | 通关 P3 假终点 → 解锁「完整模式」 |

> **分段模式** = 单独挑战任意已解锁段落

## 二、路线设计 ｜ Path & Rhythm Geometry

### 2.1 设计原则
| 原则 | 说明 | 实现依据 |
|------|------|----------|
| **节奏即几何** | 每个转向点、跳跃点、卡顿点对齐音乐拍点 | `Player.turn()` 在 `_input` 响应 `turn` action，配合 `LevelManager.anim_time` 同步动画 |
| **预判窗口 0.3s** | 玩家需在拍点前 0.3s 输入（延迟响应机制） | `Player.music_delay` + `AudioServer.get_output_latency()` 补偿 |
| **三段落几何语言递进** | P1 直线+大弯 → P2 S弯+分岔 → P3 宽阔直道+急弯 → P4 镜面 S弯+碎片门 | 编辑器中用 `Path3D` + `PathFollow3D` 铺设，触发器挂载在 `Trigger.tscn` 实例下 |
| **视觉引导优先** | 路径节点随拍点闪烁、残影指示安全线、雾/光引导视线 | `SetFog.gd`、`CameraTrigger.gd`、`Gem.gd` 闪烁逻辑复用 |

### 2.2 各段落路线拓扑

#### P1 初滞——「呼吸的峡谷」
```
起点 ──[直道 8拍]──> ├─左弯 45°─┤ ──[直道 4拍]──> ├─右弯 60°─┤ ──[直道 8拍]──> 卡顿点1
       ↑                                    ↓
    自动前行                            RGB分离提示
```
- **卡顿点**：每 8 拍触发一次，`BaseTrigger` 子节点挂 `Speed.gd(new_speed=0)` + `CameraShakeTrigger.gd`，持续 0.5s
- **新手引导区**：前 30s 碰墙不死，`Player.die()` 内 `noclip` 为真时直接返回

#### P2 回声——「残影的抉择」
```
入口 ──[雾化过渡]──> 分岔口A(残影走左) ──> 汇合 ──> 分岔口B(残影走右) ──> 汇合 ──> 收窄走廊 ──> 拱门轮廓
```
- **残影机制**：`FakePlayer.gd` 记录 3 秒前位置/旋转，`MeshInstance3D` 半透明渲染
- **安全路径判定**：残影轨迹所经 `CollisionShape3D` 区域标记 `safe_zone=true`，偏离触发 `FallPredictor.gd` 预警线变红

#### P3 终章——「破晓前的滑步」
```
山谷尽头 ──[宽阔直道 全程 0.5x speed]──> 阳光穿透云层 ──> 发光拱门
       ↑                                                           ↑
   三段式演出（镜像重叠→残影引路→近景远景）                    假终点：机车式滑步过弯→渐白→静音
```
- **慢速实现**：`Speed.gd(new_speed = base_speed * 0.5)` 挂在段落入口 `BaseTrigger` 上
- **最后 20% 恢复正速**：第二个 `Speed.gd(new_speed = base_speed)` + `CameraTrigger.gd(fov=90, duration=1.5)`

#### 2.3.1 P3 长直道三段式演出设计｜从单调到沉浸

为避免连续~70秒的长直道造成单调感，整个终章直道分为三个阶段，以**视觉焦点转移+互动元素递进**维持玩家注意力，同时紧扣「延迟/滞后」主题：

---

**第一段：镜像重叠（Reflection Overlap）——「你以为自己只有一个」**

| 设计维度 | 具体方案 |
|---------|---------|
| **场景** | 直道起点，两侧布置垂直镜面平面（平面 Mesh + screen-space reflection Shader），地面为深色镜面材质。 |
| **核心效果** | 玩家前进的镜像从单面反射逐渐变为**双侧重叠**，每侧 2~3 个镜像副本，以略带不同的延迟（0.1s、0.2s、0.3s）和透明度（0.6→0.2）依次排列，形成「自己簇拥自己」的奇观。镜像副本沿直道固定触发点逐个生成。 |
| **互动** | 镜像不阻挡，无伤害。中间穿插一次轻跳（Jump.gd height=1.5），让镜像同时起跳制造视觉震撼。 |
| **相机** | FOV 75→85 缓慢展宽，相机轻微上移，让镜面占满侧屏，强化包围感。CameraTrigger：offset.y +0.5, duration=4.0 |
| **雾效** | 雾密度从 0.008 降至 0.004，雾色从深蓝 `#003366` 渐变为 `#1A1A2E`，让镜像边界更清晰。SetFog 在段首触发。 |
| **叙事文字** | 「你以为自己只有一个——但回声从来不只一声。」——在镜像完全展开后淡入，持续 3s。 |

> **实现要点**：镜像副本使用 `FakePlayer` 的简化版——非物理、无碰撞、仅视觉 Mesh，用 `Path3D` 预录路径或匀速直线运动。每副本挂一个淡出 Tween（5s 后透明度→0 并 queue_free），避免持续渲染开销。

---

**第二段：残影引路与地面呼吸（Echo Guide & Ground Pulse）——「跟着过去的光走」**

| 设计维度 | 具体方案 |
|---------|---------|
| **场景** | 镜像渐收，地面材质从镜面切换为「发光路径材质」——随着玩家前进而从脚下向远方亮起，形成追光效果。路径材质使用 `ShaderMaterial`，以 `Player.position.y`（或 `PathFollow3D.progress`）作为 `uniform` 驱动 `emission` 强度。 |
| **残影** | 正前方 15~20 米处出现一个 `FakePlayer` 残影（使用 `Pool` 中预生成的半透明 MeshInstance3D），以 0.6x 速度沿同样的路线前进（3 秒延迟回放）。残影每 8 拍做一次转身动作（不实际影响路线），制造活着的引路者感。 |
| **路线渐隐** | 玩家自己的尾迹（RoadMaker 生成的 road mesh）开始逐渐变透明（`modulate.a` 从 1.0→0.3），仿佛现在的路正在消失，过去的路在照亮前方。 |
| **残影渐隐** | 随玩家推进，前方引路残影逐渐变淡，在第二段末尾完全透明。使用 `Tween` 在 10s 内渐变透明度。 |
| **互动** | 地面每隔 4 拍闪烁一次蓝色 Gem 碎屑（无得分收集物，纯视觉），闪烁频率与 BGM 鼓点对齐。配合 `CameraShakeTrigger.gd` 极轻微震动（power=0.1, duration=0.2），制造心跳触觉。 |
| **雾效** | 天空亮度开始抬升，太阳从 `light_energy=1.2` 缓慢升至 2.0，雾色开始混入微暖色 `#2D1B00`。为 P3 终章的破晓做预热。SetFog 在中段触发。 |
| **叙事文字** | 「跟着那道光走吧——它从三秒后来，从三秒前去。」——在残影出现时淡入。 |

> **实现要点**：地面 Shader 需要 `uniform float light_progress`（0.0→1.0），由 `SetMaterialProgress.gd`（Mode 1 组件）在 `_process` 中根据玩家 Z 轴位置实时更新。尾迹渐隐可由 `SetTailOpacity.gd`（Mode 1 组件）修改 `Player.modulate` 或 `past_translation` 相关的 mesh material。 |

---

**第三段：近景与远景的对峙（Foreground vs. Horizon）——「终点在远方，而你在当下」**

| 设计维度 | 具体方案 |
|---------|---------|
| **场景** | 路线重新实体化（尾迹透明度恢复至 0.8），但视野豁然开朗。远景占屏幕上方 2/3——不是残影，而是 **P1~P2 场景的地标剪影**（峡谷立方体柱子、P2 山谷轮廓）以微缩、高雾浓度（`fog_end=600.0`）的方式在远景中若隐若现，像记忆的地平线。 |
| **近景** | 玩家与当前路线占据屏幕下方 1/3。地面材质切换回标准深色，但带有细碎的反光颗粒（模拟镜面碎裂后的余韵）。 |
| **远景残影** | 不做。原因：此时情感需要回忆在远方，而玩家在前方——远景的 **静态剪影**（使用远景贴图或低模 LOD）比动态残影更能制造追忆过去的苍茫感。如果放残影，容易分散玩家对假终点拱门的注意力。 |
| **主体机制** | 从 0.5x 慢速开始微升（Speed.gd 0.5→0.7x），地面反光颗粒密度增加，暗示越来越接近。最后 10% 突然恢复 1.0x 正速 + FOV 90 + 轻微相机震动，制造冲刺感。 |
| **假终点拱门** | 在远景尽头逐渐亮起（Bloom 从 0.4→1.2），拱门光使用 `CrystalLightning.gdshader` 驱动，脉冲频率与心跳鼓点对齐。 |
| **叙事文字** | 「快到了……光就在前面。」——在恢复正速前淡入，持续 2s 后淡出，不干扰冲刺。 |

> **实现要点**：远景地标使用独立的远景场景节点（`Scene_Far_Horizon`），低面数模型 + 半透明雾材质，仅在 P3 激活。相机使用 `CameraTrigger` 拉远 `distance`（+5.0），让远景进入视野。最后恢复正速的 `Speed.gd` 配合 `CameraTrigger(fov=90)` 同步触发。 |

---

**三段衔接时间表（以完整模式 P3 约 90s 计时）**

| 时间段 | 阶段 | 核心事件 |
|--------|------|---------|
| P3 0s~25s | 第一段：镜像重叠 | 镜像生成 → 轻跳 → 镜像渐收 |
| P3 25s~55s | 第二段：残影引路 | 地面亮起 → 残影出现 → 尾迹渐隐 → 残影渐隐 |
| P3 55s~80s | 第三段：近景远景 | 远景开启 → 速度微升 → 尾迹恢复 → 正速恢复 |
| P3 80s~90s | 假终点拱门冲刺 | 冲刺感 → 穿过拱门 → 滑步演出 → 假终点触发 |

> **性能注意**：镜像副本和残影均使用 `MeshInstance3D` + Tween 淡出销毁，不在整个 P3 全程常驻。远景地标使用低模 LOD，总面数控制在 500 以内。镜像副本上限 6 个，残影引路同时只存在 1 个。

#### P4 回声之境——「同步率博弈」
```
拱门后 ──[镜面地面 反射 P1~P3 残影]──> 直道(碎片稀疏) ──> S弯(碎片内外侧各半) ──> 连续卡顿 S弯(高密度) ──> 碎片门(3必经碎片物理阻挡) ──> 汇聚点
```
- **同步率系统**：`LevelManager.sync_rate` (0~100%)，自然衰减 -1.5%/s，拾取 +8%
- **碎片生成**：`GemFragment.tscn` + `Gem.gd` 程序化沿 `Path3D` 两侧按密度曲线生成（见《最终关玩法设计.md》密度表）
- **碎片门**：3 个 `Gem` 实例 `body_entered` 计数，未满 3 不开启 `CollisionShape3D.disabled=false` 阻挡

## 三、场景布置 ｜ Scene Composition & Atmosphere

### 3.1 场景层级规范（编辑器中建立）
```
LevelRoot (Node3D)
├─ BasicOBJ_Group (Node3D)           # 运行时实例化：Player、CameraRoot、AnimationPlayer、MusicPlayer、GAMEUI
├─ Scene_Group (Node3D)              # 关卡几何、触发器、装饰
│  ├─ Scene_001 (Node3D)             # P1 峡谷段
│  │  ├─ Ground (Ground.tscn)        # 物理碰撞 + 视觉网格分离
│  │  ├─ Triggers (Node3D)           # 所有 BaseTrigger 实例容器
│  │  │  ├─ Trigger_Stutter_01 (Trigger.tscn) → 子节点 Speed.gd(0) + CameraShakeTrigger.gd
│  │  │  ├─ Trigger_Turn_01 (Trigger.tscn) → 子节点 ChangeDirection.gd
│  │  │  └─ ...
│  │  ├─ Props (Node3D)              # 立方体柱子、飘浮碎片、雾粒子
│  │  └─ FogVolume (Node3D)          # SetFog.gd 触发器
│  ├─ Scene_002 (Node3D)             # P2 山谷段
│  │  └─ ... 残影相关触发器、镜面碎片投影
```

### 3.4 运行时雾光切换实现（`SetFog.gd` 扩展）
```gdscript
@tool
extends Node
class_name SetFog

@export_group("目标环境")
@export var target_env: WorldEnvironment  # 场景中唯一的 WorldEnvironment 节点
@export var transition_duration: float = 2.0

@export_group("Fog 参数（线性/指数二选一）")
@export var fog_enabled: bool = true
@export var fog_mode: int = 0  # 0=LINEAR, 1=EXP, 2=EXP2
@export var fog_begin: float = 15.0
@export var fog_end: float = 120.0
@export var fog_density: float = 0.008
@export var fog_color: Color = Color("#003366")
@export var fog_height_enabled: bool = false
@export var fog_height_min: float = -5.0
@export var fog_height_max: float = 20.0
@export var fog_height_density: float = 0.12

@export_group("Sky 参数")
@export var sky_energy: float = 1.2
@export var sky_ground_color: Color = Color("#1A1A2E")
@export var sky_horizon_color: Color = Color("#FFD700")
@export var sky_zenith_color: Color = Color("#FFA500")

@export_group("Sun 参数")
@export var sun_node: DirectionalLight3D
@export var sun_rotation: Vector3 = Vector3(-55, 30, 0)
@export var sun_color: Color = Color("#FFE87C")
@export var sun_energy: float = 2.8
@export var sun_size: float = 0.53
@export var volumetric_intensity: float = 0.35

@export_group("Bloom / Tonemap / Adjustment")
@export var bloom_intensity: float = 0.4
@export var bloom_threshold: float = 1.2
@export var contrast: float = 1.05
@export var saturation: float = 1.1

var _tween: Tween

func trigger(_body: Node3D) -> void:
    if not target_env: return
    _tween?.kill()
    _tween = create_tween()
    _tween.set_parallel(true)
    _tween.set_trans(Tween.TRANS_SINE).set_ease(Tween.EASE_IN_OUT)

    # --- Fog ---
    _tween.tween_property(target_env, "environment/fog/enabled", fog_enabled, transition_duration)
    _tween.tween_property(target_env, "environment/fog/mode", fog_mode, transition_duration)
    _tween.tween_property(target_env, "environment/fog/begin", fog_begin, transition_duration)
    _tween.tween_property(target_env, "environment/fog/end", fog_end, transition_duration)
    _tween.tween_property(target_env, "environment/fog/density", fog_density, transition_duration)
    _tween.tween_property(target_env, "environment/fog/color", fog_color, transition_duration)
    _tween.tween_property(target_env, "environment/fog/height_enabled", fog_height_enabled, transition_duration)
    _tween.tween_property(target_env, "environment/fog/height_min", fog_height_min, transition_duration)
    _tween.tween_property(target_env, "environment/fog/height_max", fog_height_max, transition_duration)
    _tween.tween_property(target_env, "environment/fog/height_density", fog_height_density, transition_duration)

    # --- Sky (ProceduralSky) ---
    var sky: ProceduralSky = target_env.environment.sky.get_sky() as ProceduralSky
    if sky:
        _tween.tween_property(sky, "energy", sky_energy, transition_duration)
        _tween.tween_property(sky, "ground_color", sky_ground_color, transition_duration)
        _tween.tween_property(sky, "horizon_color", sky_horizon_color, transition_duration)
        _tween.tween_property(sky, "zenith_color", sky_zenith_color, transition_duration)

    # --- Sun ---
    if sun_node:
        _tween.tween_property(sun_node, "rotation_degrees", sun_rotation, transition_duration)
        _tween.tween_property(sun_node, "light_color", sun_color, transition_duration)
        _tween.tween_property(sun_node, "light_energy", sun_energy, transition_duration)
        _tween.tween_property(sun_node, "light_size", sun_size, transition_duration)
        _tween.tween_property(sun_node, "volumetric_intensity", volumetric_intensity, transition_duration)

    # --- Bloom / Adjustment ---
    _tween.tween_property(target_env, "environment/bloom/intensity", bloom_intensity, transition_duration)
    _tween.tween_property(target_env, "environment/bloom/threshold", bloom_threshold, transition_duration)
    _tween.tween_property(target_env, "environment/adjustment/contrast", contrast, transition_duration)
    _tween.tween_property(target_env, "environment/adjustment/saturation", saturation, transition_duration)

    # P3 动态参数可在 Inspector 里再建一个 SetFog 实例，配置终值，由 CameraTrigger(时间) 触发
```
> **用法**：每个段落入口放一个 `Trigger.tscn` 实例，挂 `SetFog.gd`，填好该段落的目标参数；`BaseTrigger.one_shot=true, require_playing=true`。P3 破晓渐变再放第二个 `SetFog` 实例，`use_time=true, trigger_time=110`（anim_time 秒）触发。

## 四、玩家与场景互动 ｜ Player-Scene Interaction

### 4.1 核心输入→响应链路
```
InputEvent("turn") → Player._input() → Player.turn() 
    → rotation_degrees = current_direction (即时视觉转向)
    → velocity 重新计算 (物理下一帧生效)
    → new_line() 产生尾迹 MeshInstance3D
    → LevelManager.anim_time 同步 AnimationPlayer.seek()
    → 音乐同步：_play_music_from_level_data()
```
- **延迟响应 0.3s**：`music_delay > 0` 时，`turn()` 立即移动、音乐延后 `create_timer(music_delay)` 播放（对齐 Unity 行为）

### 6.1 「滞后响应」核心手感参数

### 6.2 残影系统技术规格 (`FakePlayer.gd`)
```gdscript
# 核心字段
var record_buffer: Array[Transform3D] = []  # 固定长度 180 帧 (3s @ 60fps)
var replay_mesh: MeshInstance3D
var material: StandardMaterial3D  # transparency=0.3, render_mode=BLEND

func _physics_process(_delta):
    record_buffer.append(global_transform)
    if record_buffer.size() > 180: record_buffer.pop_front()
    if Engine.get_process_frames() > 180:  # 3s 后开始回放
        replay_mesh.global_transform = record_buffer[0]
        record_buffer.pop_front()
```
- **编辑器预览**：`@tool` 模式下 `_ready()` 生成预览残影路径
- **性能**：最多 3 个残影实例（P1/P2/P3 各一），P4 同时显示用 `GeometryInstance3D` 批次渲染

### 6.3 同步率系统 (`SyncRateManager.gd` —— P4 专用单例)
```gdscript
class_name SyncRateManager extends RefCounted
signal changed(value: float)
signal died(reason: String)

var rate: float = 60.0  # 0~100
var decay_per_sec: float = 1.5
var pickup_gain: float = 8.0

func _process(delta):
    rate = clamp(rate - decay_per_sec * delta, 0, 100)
    changed.emit(rate)
    if rate >= 100: died.emit("over_sync")
    _update_audio_bus(rate)
    _update_edge_glow(rate)

func collect_fragment(): rate = clamp(rate + pickup_gain, 0, 100)
```
- **音频总线自动化**：`AudioServer.set_bus_send_volume_pre_fader(bus_idx, send_idx, db_from_sync_rate(rate))`
- **边缘光晕**：`CanvasModulate` + `ShaderMaterial` 根据 `rate` 插值青蓝→金→红金

### 6.4 假终点演出导演 (`FakeEndingDirector.gd` 新建)
```gdscript
@tool extends Node
@export var arch_gate: Node3D
@export var player: Player
@export var camera: CameraFollower
@export var music: AudioStreamPlayer

func trigger_fake_ending():
    # 1. 玩家穿过拱门触发
    player.allowTurn = false
    # 2. 机车式滑步转向 (复用 Jump.gd height=0.5 + 旋转插值)
    var tween = create_tween()
    tween.tween_property(player, "rotation_degrees", player.rotation_degrees + Vector3(0, 90, 0), 0.6)
    tween.set_trans(Tween.TRANS_SINE).set_ease(Tween.EASE_IN_OUT)
    # 3. 渐白
    tween.tween_callback(_fade_to_white).set_delay(0.6)
    # 4. 音乐戛然而止
    tween.tween_callback(music.stop.bind()).set_delay(0.8)
    # 5. 文字淡入
    tween.tween_callback(_show_fake_ending_text).set_delay(1.0)
```
- **解锁完整模式**：动画结束后 `ConfigFile` 写入 `full_mode_unlocked=true`，关卡选择界面读取刷新卡片状态
