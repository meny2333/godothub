## 一、项目概述

| 项目       | 内容                                     |
| -------- | -------------------------------------- |
| **项目名称** | 弄影 Afterimage（中文《弄影》/ 英文 AFTERIMAGE）       |
| **引擎**   | Godot 4.x                              |
| **平台**   | Web（优先）+ Windows                       |
| **类型**   | 3D 节奏线控跑酷                              |
| **核心机制** | 玩家控制一条线沿路径前进，跟随音乐节奏点击转向，体验「时间滞后」的叙事与玩法 |
| **关卡结构** | 单关卡分 3 段落 + 完整模式，段落解锁制                 |
| **主题**   | 滞后 Delay——行动、情感、记忆的延迟与回响               |
|          |                                        |

### 叙事前提

玩家控制一台用于记录道路节拍的小机器人。时间开始迟疑后，它在暖黄色峡谷中醒来，大部分核心记录已经遗失；唯一仍在循环的提示是：“跟随前方微光，别停下。”

这条提示给出当下的行动目标，但不解释谁留下它、微光通向哪里。随着残影、假终点和镜面回声出现，机器人会逐步理解：它记录的不是单纯的节拍，而是这个世界被滞后的时间。

## 二、主题诠释：「滞后」的三层含义

| 层次       | 游戏内表现                | 玩家感受             |
| -------- | -------------------- | ---------------- |
| **行动滞后** | 点击后线条延迟响应；路径偶尔卡顿     | 操作上的「不跟手」，体会失控感  |
| **记忆滞后** | 场景中出现几秒前的残影；路线与过去重叠  | 视觉上的「回声」，仿佛记忆追上来 |
| **情感滞后** | 音乐从模糊到清晰，终章爆发；色调从暗到明 | 情绪上的「迟到的温柔」，结尾释然 |
**开场白**：
>BoomBit 的《Through The Fog》里，有一关叫 _Peaceful Stagnation_。 停滞，但宁静。
现在，我们用 Godot 把它重新讲成一个关于**滞后**的故事。
你控制一条线。 它本该随你指尖即刻转向—— 但在这个世界里，点击之后，要等一等。
等 0.3 秒。 等一个节拍。 等那个**滞后的自己**，从身后追上来。
行动滞后于意志， 记忆滞后于时光， 温柔滞后于错过。
穿过那扇发光的拱门， 你以为已经抵达。
但真正的答案—— 还在更远处。
跟紧那个迟到的回声。 它知道真正的路。

## 四、核心玩法机制

### 基础操作
- **点击/空格**：线条向左/右转向（或点击屏幕左右半区）
- **长按**：某些路段需要持续按住以维持方向
- **节奏提示**：路径上的节点随音乐节拍闪烁

### 「滞后」专属机制

| 机制名 | 说明 | 出现段落 |
|---|---|---|
| **延迟响应** | 点击后 0.3 秒线条才转向，需要预判 | 段落 1 后期、段落 3 |
| **卡顿判定** | 特定节拍点线条突然减速，音乐失真 | 段落 1 |
| **残影跟随** | 半透明「过去的自己」走在前方/后方，提示安全路径 | 段落 2 |
| **慢速爆发** | 全程慢速但音乐清晰，最后突然恢复正常速度 | 段落 3 |
| **回声判定** | 错过节拍后，下一个节拍点会闪现「错过的路径」，给第二次机会 | 全段落（低难度辅助） |

## 五、UI 流程设计（完成度 checklist）

```
[启动画面] → [主菜单] → [关卡选择] → [段落选择/完整模式] → [游戏内 HUD] → [结算页] → [重试/返回]
	 ↓           ↓           ↓                ↓                  ↓           ↓
  Logo+主题   开始游戏    3段落+完整模式    暂停菜单(设置/退出)   分数+评级    保存进度
  淡入淡出    设置        锁/解锁状态       进度条+节奏提示      主题文字     解锁下一段
```

### 各界面要点

| 界面 | 功能 |
|---|---|
| **主菜单** | 背景是缓慢流动的线条残影；标题「弄影 / AFTERIMAGE」带轻微 glitch 效果 |
| **关卡选择** | 3 张段落卡片横向排列，未解锁的显示锁图标+模糊预览；完整模式在最右侧 |
| **设置** | 音量、灵敏度、延迟校准（玩家可调整输入延迟补偿）、画质 |
| **游戏内 HUD** | 顶部进度条、左下角连击数、右下角暂停按钮；极简，不干扰沉浸 |
| **结算页** | 显示完成度%、评级（S/A/B/C）、主题文字（每段落不同）、解锁提示 |
| **暂停菜单** | 继续、重试、返回关卡选择、设置 |

## 六、美术风格

### 整体方向
- **低多边形（Low Poly）** + **风格化渲染**
- 色调：段落 1 偏青绿 → 段落 2 偏灰蓝 → 段落 3 偏暖金
- 氛围：静谧、孤独、略带忧伤，终章温暖

### Shader 效果（加分项）

| 效果 | 用途 |
|---|---|
| **RGB 分离（Chromatic Aberration）** | 卡顿瞬间、情绪高点 |
| **雾效（Fog）** | 营造距离感和神秘感 |
| **残影拖尾（Trail/Afterimage）** | 段落 2 的核心视觉 |
| **Bloom 辉光** | 终章阳光穿透、终点光芒 |
| **时间扭曲（Time Warp）** | 慢速播放时的画面轻微扭曲 |

## 七、音乐与音效

### 音乐
- **风格**：钢琴 + 弦乐 + 电子氛围音
- **结构**：3 段落共用同一主题动机，逐层叠加，终章完整呈现
- **BPM 变化**：80 → 100 → 120，形成递进
- **实现**：用 Godot 的 `AudioStreamInteractive` 或分段音频 + 代码切换，确保段落间无缝衔接

### 音效
| 事件 | 音效 |
|---|---|
| 点击转向 | 清脆的钢琴单音（与 BGM 和弦匹配） |
| 错过节拍 | 低沉的「嗡」声 + 轻微失真 |
| 连击达成 | 叠加的和弦泛音 |
| 段落切换 | 环境音过渡（风声 → 弦乐滑音） |
| 通关 | 主题旋律完整奏响 + 混响渐强 |
